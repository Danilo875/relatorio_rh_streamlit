# Projeto de Análise de Dados de Recursos Humanos

Este projeto consiste em um aplicativo web interativo desenvolvido com **Streamlit**, que permite a análise e visualização dos dados de recursos humanos de uma empresa.

## Características Principais

- Interface amigável com navegação lateral, contendo páginas para:
  - Visualização geral dos dados (Painel).
  - Simulação de aposentadoria, para identificar funcionários elegíveis.
  - Tabela para extração e exportação dos dados filtrados em formato CSV.
- Sistema de seleção de idioma entre Português e Inglês.
- Visualizações dinâmicas construídas com **Plotly**, incluindo gráficos de barras, gráficos de rosca e outras representações.
- Manipulação e agregação dos dados utilizando **Pandas**.
- Estrutura de código modular, facilitando a manutenção e expansão do aplicativo.

## Tecnologias Utilizadas

- [Streamlit](https://streamlit.io/) para construção da interface web.
- [Pandas](https://pandas.pydata.org/) para manipulação de dados.
- [Plotly](https://plotly.com/python/) para visualização gráfica interativa.

# Como Rodar o Projeto
1. Clone o repositório

2. Entre na pasta do projeto

3. Crie e ative um ambiente virtual (opcional, mas recomendado)

4. Instale as dependências:
pip install -r requirements.txt

5. Execute o aplicativo Streamlit:
streamlit run main.py

6. O aplicativo abrirá no navegador padrão, geralmente em http://localhost:8501

# Human Resources Data Analysis Project

This project consists of an interactive web application developed with **Streamlit**, which allows the analysis and visualization of a company's human resources data.

## Main Features

- User-friendly interface with sidebar navigation, containing pages for:
  - General data overview (Dashboard).
  - Retirement simulation to identify eligible employees.
  - Table for extracting and exporting filtered data in CSV format.
- Language selection system between Portuguese and English.
- Dynamic visualizations built with **Plotly**, including bar charts, donut charts, and other representations.
- Data manipulation and aggregation using **Pandas**.
- Modular code structure, facilitating maintenance and expansion of the application.

## Technologies Used

- [Streamlit](https://streamlit.io/) for building the web interface.
- [Pandas](https://pandas.pydata.org/) for data manipulation.
- [Plotly](https://plotly.com/python/) for interactive data visualization.

# How to Run the Project

1. Clone the repository

2. Navigate to the project folder

3. Create and activate a virtual environment (optional but recommended)

4. Install dependencies:
pip install -r requirements.txt

5. Run the Streamlit app:
streamlit run main.py

6. The app will open in the default browser, usually at http://localhost:8501
